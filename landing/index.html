Privacy

What stays on your machine, stays on your machine.

AIOS is local-first by design. Imports are explicit and user-initiated — never silent.

  • No auto-reading of browser profile directories.
  • No silent scraping of cookies.
  • Provider secrets stay server-side and are never returned raw to the frontend.
  • Audit events store only masked fingerprints — provider, timestamp, action, last4.

How it works

From zero to chatting in five steps.

The first time you open AIOS, the Setup Assistant walks you through everything. No config files to hand-edit.

  1. 1

    Start

    Run npm install && npm start — the AIOS desktop opens in its own native window. The Setup Assistant launches automatically on first run.

  2. 2

    Pick a provider

    Choose from 20+ providers — frontier labs, regional models, local runtimes like Ollama, or GitHub Copilot — then select the model you want as your default.

  3. 3

    Connect

    Sign in with the GitHub device flow for Copilot, or paste an API key. Secrets are stored server-side and never returned raw to the browser.

  4. 4

    Test

    One click runs a minimal round-trip against your provider so you know the connection works before you rely on it.

  5. 5

    Finish

    You land on the desktop. Open AI Chat, the Browser, Notes, Files, or the Terminal — and get to work.
